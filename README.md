# Tamarit Affiliator

Tamarit Affiliator es una aplicación MERN (MongoDB, Express, React, Node.js) para la gestión de usuarios, tareas, enlaces de afiliados y accesorios, pensada para facilitar la administración y seguimiento de campañas de afiliación.

## Características principales

- **Autenticación de usuarios** (registro, login, logout, verificación por token)
- **Gestión de perfil** con campos bancarios y estado de completado
- **Gestión de tareas** (CRUD)
- **Gestión de accesorios** (CRUD)
- **Gestión de enlaces de afiliado** (crear, listar, eliminar, copiar)
- **Avisos dinámicos** en el navbar según el estado del perfil del usuario
- **Frontend en React** con Context API para la gestión global de estados
- **Backend en Node.js/Express** con controladores y rutas RESTful
